# Cursor skill name collisions

Generated by `scripts/link-agent-skills.sh`. Cursor indexes one-level
directories under `.cursor/skills/<name>/SKILL.md`. When two packs
share a `name:` field, the **first pack in flatten order** keeps the
short slash command and the later pack is installed as
`<pack>-<name>`.

Flatten order is listed in `PACK_ORDER` inside the linker (gstack
first, awesome-copilot last). Re-run the linker after adding a pack.
