# Build one TDD slice

```text
Use test-driven-development (superpowers). If this host has /build (addyosmani/agent-skills), run that instead and still keep TDD.

Plan or spec: [path]
Slice: [one checkbox or one acceptance line]

Write a failing test first. Then write only the code that makes that test pass. Then stop.

Do not start the next slice. Do not /ship. Do not expand scope.

If this is a throwaway prototype, generated code, or config, say so and ask before skipping the failing test.

End with: test command, result, files changed.
```
