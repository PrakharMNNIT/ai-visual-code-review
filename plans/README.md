## Findings considered and rejected

- Rate-limit skip for localhost when `NODE_ENV !== 'production'`: by-design for a local git tool. `createRateLimit` in `server.js` already keeps the skip off under `NODE_ENV=test`.
- `path.resolve(...).startsWith(cwd)` prefix check: `DiffService.isValidFilePath` already rejects `..` and absolute paths, so the classic `/cwd` vs `/cwd-evil` prefix bug is not reachable on the file-diff route.
- `https_proxy` / local `git` allowlists: standard conventions, not findings.
- Vendored skill trees under `.claude/skills` and `.agents/skills`: third-party content, not this app’s runtime.
- Live CSP `script-src 'self' 'unsafe-inline'`: the page is a single HTML file with inline scripts. Unused `src/middleware/security.js` nonce CSP cannot apply until HTML is templated. Not a plan until HTTP intake is one module (architecture candidate, not a 005–009 item).
- `GitService.execute` silently dropping args that match `/[;&|`$(){}[\]\\]/`: `DiffService.isValidFilePath` already rejects those characters on `/api/file-diff`. Not a separate finding.
- Activating the GET `cacheMiddleware` by moving it above `app.get`: would stale `/api/health` staged counts. Plan 008 deletes it instead.
- `test/utils.js` email/score helpers: unused by the product; ignore (fixture leftovers, not a product bug).
